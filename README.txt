TRIVOX SOLUTIONS WEBSITE
========================
Open index.html in a browser (or upload the folder to a host) to view the site.

Folder
  index.html            the page (all text and SEO tags)
  css/style.css         all styling
  js/main.js            all animations and interactions
  assets/logo.webp      hero logo (optimized)
  assets/logo-sm.webp   nav and footer logo
  assets/favicon.png    browser tab icon
  robots.txt, sitemap.xml   replace YOUR-DOMAIN.com with your real domain

Your phone number (0326 4088500 / +923264088500) is in index.html
and js/main.js (WhatsApp link). Search for 923264088500 to change it.

To publish: upload the whole folder to Netlify, Vercel, GitHub Pages
or any web host. Then add <link rel="canonical" href="https://YOUR-DOMAIN.com/">
inside <head> of index.html.
